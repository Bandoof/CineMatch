# Рев’ю CineMatch — 9 жовтня 2026

Перевірено локальну версію: рекомендації, підбір смаку, профілі, українську мову,
обробку помилок і збереження списків. Це перевірка коду та поведінки застосунку;
нових результатів ML-бенчмарку або публікації на GitHub не заявлено.

## Що виправлено

| Проблема | Результат |
|---|---|
| Немає списку на потім | Фільми й серіали додаються з підбору та рекомендацій; є окрема вкладка, видалення й позначення перегляду. |
| Перегляд відомий лише через оцінку | «Уже дивився» прибирає назву з рекомендацій і підбору. Оцінка необов’язкова; її відсутність не замінюється вигаданим балом. |
| Нові списки могли загубитися при перенесенні | JSON schema 4 і локальне збереження містять обидва списки; старі профілі імпортуються. Потрібно натискати «Зберегти локально» після змін. |
| Оцінки тільки серіалів не персоналізують фільми при alpha=1 | Для такого профілю Hybrid використовує жанровий сигнал і популярність; оцінок фільмів для моделі не вигадується. Фільмовий бенчмарк не змінено. |
| Український фільтр без файла перекладів дає порожню сторінку | За відсутності перекладів фільтр вимикається; каталог залишається доступним з оригінальними назвами. |
| Демопрофіль не позначено на всіх вкладках | Попередження про демонстраційні оцінки видно незалежно від вкладки. |
| З’єднання SQLite не закривалися явно | Додано гарантоване закриття й перевірку відкату невдалої транзакції. |
| Вимкнені постери виглядали як помилка завантаження | Текст тепер пояснює, що показ постерів вимкнено. |
| ImportError показує користувачу traceback і локальні шляхи | Невелика захищена точка входу перехоплює помилки імпорту та виконання. На сторінці нейтральне повідомлення; подробиці й випадковий код звернення — у журналі сервера. |
| Немає сторінки запланованих робіт | Додано перемикач технічних робіт українською й англійською та кнопку повторної спроби. Під час робіт каталог і моделі не завантажуються. |

Реалізація: `app/interface.py`, `app/streamlit_app.py`, `app/recommender.py`,
`src/profiles.py`, `src/discovery.py`, `scripts/maintenance.py`.

## Що покращувати далі

1. **Сучасний каталог фільмів.** Наявні фільми MovieLens закінчуються 1998 роком.
   Додати сучасні назви через надійні ідентифікатори й окремо розрізняти фільми,
   для яких є навчальні оцінки, та нові назви з рекомендаціями лише за змістом.
   Не видавати таке розширення за автоматичне покращення collaborative-моделі.

2. **Баланс фільмів і серіалів у «Усе».** На перевіреному каталозі порожній
   український профіль отримує 10 серіалів із 10. Оцінки MovieLens і TVmaze мають
   різні шкали та різний спосіб формування; їхнє поточне зіставлення евристичне.
   Варто дати користувачу бажану частку фільмів/серіалів або показувати окремі
   добірки, а потім оцінювати якість змішаного ранжування на реальних взаємодіях.

3. **Автозбереження особистого профілю.** Зараз збереження явне, а локальні
   іменовані профілі спільні для інсталяції. Для публічного сайту потрібні окремі
   профілі користувачів, автоматичне збереження та видимий стан «Збережено».

4. **Швидші повторні дії.** Усі вкладки Streamlit обчислюються під час кожної
   взаємодії, навіть коли видно одну. Зробити сторінки з окремим завантаженням і
   кешувати результати за профілем/фільтрами. Спочатку виміряти час; кількісного
   тесту продуктивності в цьому рев’ю не проводилося.

5. **Краща поведінка при недоступному постері.** Заглушка є для відсутнього URL,
   але збій зовнішнього сервера зображень може дати зламане зображення браузера.
   Додати клієнтську заглушку для помилки завантаження й перевірити цей сценарій.

6. **Надійне публічне розгортання.** Обробка помилок працює, коли Streamlit
   запущений. Для зупиненого сервера потрібна незалежна сторінка недоступності
   на рівні хостингу, перевірка стану й контрольований перезапуск сервісу.

## Перевірки

- Windows / Python 3.10: **33 тести пройшли**, Ruff без зауважень.
- У браузері перевірено додавання фільму з підбору та серіалу з рекомендацій
  до одного списку, позначення перегляду без оцінки й появу панелі необов’язкової
  оцінки. Збережено фактичні скриншоти списку, позначення перегляду та технічних робіт.
- Тести перевіряють обидва списки, відсутність вигаданих оцінок, необов’язкову
  оцінку після перегляду, скасування, локальне збереження/завантаження, JSON старих
  версій, canonical aliases і серіали.
- Окремо змодельовано ImportError, помилку виконання, українські та англійські
  повідомлення, технічні роботи й повернення до звичайного режиму.
- Linux-перевірку нової версії запустити не вдалося: Docker Engine зараз
  недоступний. Попередній Linux-прогін 22 тестів стосувався старішої версії.
- Поточні виміряні ML-метрики залишаються історичним фільмовим бенчмарком;
  якість рекомендацій серіалів і нового fallback окремо не виміряно.
