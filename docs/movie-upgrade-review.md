# Повторне рев’ю та оновлення CineMatch — 9 жовтня 2026

## Виправлення та перевірені зміни

- **Каталог:** 1 664 → 10 123 фільми; додано 8 459 назв. Усі старі ID й aliases
  залишено, а користувачі двох наборів мають різні простори ID. Оцінки, список
  на потім та позначки перегляду не перенумеровуються. Реальні 0,5-зіркові
  оцінки джерела збережено; пошук та редагування також підтримують пів зірки.
- **Назви:** «Темний лицар» (2008), «1+1» (2011), «Інтерстеллар» (2014)
  доступні. «Леон» (1994) — це наявний ID 55 / The Professional, а не дубль.
  Перевірено IMDb-відповідності, українські назви й посилання на зображення.
- **Пошук:** українські/англійські назви, aliases Wikidata, Léon/Leon,
  буквальна пунктуація «1+1». Прямий пошук знаходить також переглянуті назви.
  Знак «+» зберігається, щоб «1+1» не збігалося з фрагментами років інших назв.
  Назви ремейків не об’єднуються лише через схожу назву: рік входить у ключ.
- **Рекомендації «Усе»:** збалансовані місця фільмів і серіалів; якщо
  один тип має замало кандидатів, другий заповнює решту. Окремі типи зберігають
  звичайне ранжування. Непорівнювані оцінки джерел більше не витісняють усі фільми.
- **«Не цікавить»:** назва виключається; схожість жанрів дає обмежений
  м’який штраф (до 20% діапазону оцінки алгоритму). Ніяких вигаданих оцінок
  або історії перегляду. Є скасування останнього, окремого й усіх виборів;
  сигнал зберігається у профілі. Це жанрова евристика, не розуміння сюжету.
- **Швидкість і пам’ять:** Item-KNN використовує розріджені спостереження,
  обчислює лише схожості з оціненими назвами й обмежує тимчасові масиви.
  Основні матриці займають 4 825 104 байти; квадратний масив каталогу не
  створюється. Формулу порівняно з попередньою щільною реалізацією.
  Повторні обчислення профілю кешуються, результати захищено від зміни іншими
  викликами. Пошук назв і підбір використовують прямий доступ до записів.
- **Пояснення:** коли жанрова вага Hybrid дорівнює нулю, картка пояснює
  фактичні collaborative/quality сигнали, не приписує відбір жанровій моделі.
- **Джерела:** завантаження метаданих відновлюється після тайм-аутів. Є 6 111
  українських назв фільмів, 395 назв серіалів та 9 395 посилань на зображення фільмів.

## Модель: що показало порівняння

Дані: 200 836 реальних подій оцінювання; глобальний часовий split
160 668 / 20 084 / 20 084. 64 варіанти параметрів вибиралися лише на validation.
Вибрано ALS 32 factors, regularization 10, 15 epochs. Для профілю з оцінками
фільмів Hybrid — 60% collaborative + 40% зваженої якості спільноти;
genre weight у цьому запуску дорівнює нулю. Для профілю лише із серіалами
зберігається жанровий fallback. Модель застосунку навчено окремо на всіх даних.

Порівняння з попередньою архітектурою, перенавченою на тих самих нових даних:

| Метрика Top-10 | Попередня | Оновлена |
|---|---:|---:|
| Precision | 0,0536 | 0,0607 |
| Recall | 0,0216 | 0,0298 |
| NDCG | 0,0582 | 0,0563 |
| Coverage | 0,0208 | 0,0128 |

**Немає доказу загального підвищення точності:** більше влучних результатів,
але трохи гірше ранжування й менше покриття. Вибірка лише 28 warm users;
парний 95% інтервал різниці NDCG [-0,0260; 0,0184] містить нуль.
Поведінка «Не цікавить», баланс типів і серіали перевірені тестами,
але не мають власного виміряного benchmark якості. Статистики старого 100K
не можна прямо порівнювати з новою вибіркою.

Джерело розширення — [офіційний MovieLens latest-small](https://files.grouplens.org/datasets/movielens/ml-latest-small-README.html).
Це development snapshot до 2018 року, не повний каталог 2026 року й не
стабільний академічний benchmark. Checksum джерела записано у звіті.

## Наступні пріоритети

1. Каталог нових релізів через надійний metadata API; окремий fallback для
   фільмів без навчальних взаємодій. Не переносити на них чужі оцінки.
2. Власна перевірка для 5–10 стартових оцінок і сигналів «Не цікавить»;
   заміряти задоволення користувачів, а не підбирати параметри по test.
3. Ознаки сюжету, акторів та режисерів: жанри надто грубо описують, що
   конкретно не цікавить. Узгодити вподобання з позитивними оцінками.
4. Ізольовані особисті профілі перед публічним запуском. Автоматичне локальне
   запам’ятовування вже працює, але поточний профіль спільний для інсталяції.
5. Перевірка збоїв зовнішніх зображень і незалежна сторінка недоступності
   для публічного розгортання. Поточна нейтральна сторінка працює всередині сервера.

## Перевірка

Windows / Python 3.10: 46 автоматичних тестів, Ruff. Покрито збереження старих ID,
ізоляцію користувачів джерел, пів зірки, aliases і ремейки, еквівалентність KNN,
обмеження пам’яті, баланс і короткі списки, вплив «Не цікавить», скасування,
збереження профілів, захист кешованих результатів та попередні сценарії помилок.
Linux / Docker / Python 3.11: ті самі 46 тестів пройшли, Ruff пройшов.
Тести виконано без мережі та без монтування персональних даних.
Запуску GitHub Actions або публікації на GitHub не заявлено.

## Автоматичне запам’ятовування

Оцінки, переглянуте, список на потім, «Не цікавить», «Не дивився», мова та
фільтри зберігаються після змін і відновлюються при поверненні. Перемикач у
бічній панелі дозволяє вимкнути функцію. Демооцінки не замінюють особистий
знімок. Окрема таблиця SQLite не змінює іменованих профілів. Новіші зміни
іншої вкладки захищені від випадкового перезапису; збій сховища дає
нейтральне повідомлення та залишає можливість експорту поточної вкладки.

Перевірено відновлення всіх сигналів у новій сесії, вимкнення/повторне
ввімкнення, очищення, деморежим, незмінність іменованих профілів, конфлікт
двох вкладок, пошкоджені дані й недоступний файл. У справжньому браузері
«Інтерстеллар» зберігся у списку після оновлення; тестову позначку прибрано.
