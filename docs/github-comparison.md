## Рекомендована черговість

1. **Актуальний каталог.** Наявний MovieLens latest-small обмежений 2018 роком. Нові назви можна рекомендувати за підтвердженими описами/жанрами навіть без користувацьких оцінок. Відсутні оцінки не слід вигадувати.
2. **Пошук із підказками.** Додати український набір перевірок: «інтерстелар», «темний лицар», «Leon», «Léon», «1+1». Короткі цифрові запити повинні залишатися буквальними. При нечіткому збігу показувати рік і тип, щоб людина підтвердила потрібну історію.
3. **Багатший змістовий підбір.** Замість лише жанрів використати TF-IDF описів, ключових слів, акторів і режисерів. Порівняти його з жанровою моделлю на тому самому часовому розділенні; нейромережа не є обов’язковою першою зміною. Мова інтерфейсу не повинна змінювати ID фільму.
4. **Контроль смаку.** Додати зрозумілі окремі причини відмови: «не люблю жанр», «не зараз», «не цікавить саме ця історія». Зараз «Не цікавить» дає обмежене жанрове зниження пріоритету; це може бути занадто загально для змішаних жанрів.
5. **Персональні облікові записи перед публічним запуском.** Локальне автоматичне запам’ятовування вже реалізоване, але це один поточний профіль інсталяції. Публічний сервіс потребує ізольованих профілів і входу. Docker сам по собі не розв’язує цю задачу.

## Що вже є в CineMatch

Автоматичне локальне збереження, оцінки, «Переглянути пізніше», «Уже дивився», слабкий негативний сигнал «Не цікавить», українські назви, постери, порівняння моделей і чесний часовий benchmark. Тому повторне додавання цих базових можливостей зі сторонніх прикладів не є наступним пріоритетом. Наявний кеш моделей і розріджений Item-KNN також уже вирішують частину проблем швидкодії.

Модуль [python_evaluation.py](https://github.com/recommenders-team/recommenders/blob/main/recommenders/evaluation/python_evaluation.py) містить реалізації diversity, novelty та serendipity. Наш висновок: наступну модель слід оцінювати також за тим, чи вона допомагає знайти нові доречні історії, а не лише повторює популярні назви. Чужі показники точності не можна порівнювати напряму з нашими: відрізняються дані, розділення й користувачі.

Жодні сторонні pickle-моделі не завантажувалися й не виконувалися; сторонній код не копіювався. Це самостійні пропозиції на основі зазначених джерел.
