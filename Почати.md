# CineMatch — як почати

Інтерфейс український за замовчуванням. У верхній частині сторінки є перемикач **Мова / Language**.

## На цьому комп’ютері

Відкрийте **START_CINEMATCH.cmd** у цій папці. Потім перейдіть на
[CineMatch](http://127.0.0.1:8501). Якщо застосунок уже працює, просто відкрийте посилання.
Файл запуску перевіряє сервер, за потреби запускає його у фоні й відкриває сторінку.
Після перезавантаження комп’ютера відкрийте **START_CINEMATCH.cmd** знову.
Журнал запуску зберігається у `data/runtime/server.log`.

1. Оберіть «Усе», «Фільм» або «Серіал» у полі «Що подивитися».
2. У «Для вас → Підбір смаку» застосунок сам показує фільм чи серіал із зображенням.
   Натисніть оцінку від 1 до 5 або «Не дивився» — наступна історія з’явиться автоматично.
   Випадкову відповідь можна скасувати.
3. Додайте 5–10 оцінок, зокрема історії, які не сподобалися.
4. Відкрийте «Для вас → Рекомендації». Жанри й роки — у бічній панелі; модель і різноманітність —
   у «Уточнити рекомендації». За потреби тут можна знайти конкретну історію за назвою.
5. Автозапам’ятовування ввімкнене: зміни відновляться при поверненні.
   У «Моїх оцінках» можна додатково створити іменовану копію або експортувати JSON.

## Переглянути пізніше та історія перегляду

У «Підборі смаку» й «Рекомендаціях» натискайте **Переглянути пізніше**.
Збережені фільми та серіали доступні на однойменній вкладці, незалежно від
поточних фільтрів. Додавання до списку не ставить оцінку.

Якщо рекомендацію вже бачили, натисніть **Уже дивився**. Вона зникне з підбору
й рекомендацій. Можна поставити оцінку, залишити без оцінки або скасувати позначку.
Історії без оцінки доступні у «Моїх оцінках»: їх можна оцінити або повернути до
рекомендацій. Переглянуте автоматично прибирається зі списку «Переглянути пізніше».

**Запам’ятовувати автоматично** у бічній панелі ввімкнене за замовчуванням.
Оцінки, усі списки й позначки, мова та фільтри зберігаються на цьому комп’ютері.
Після оновлення сторінки або перезапуску сервера вони відновляться. Тут один
спільний поточний профіль; демооцінки не замінюють його. Функцію можна вимкнути.

Для окремої іменованої копії відкрийте **Мої оцінки**, вкажіть назву профілю й
натисніть **Зберегти локально**. JSON містить усі списки; старі експорти сумісні.
Якщо інша вкладка зберегла новіші зміни або сховище недоступне, з’явиться
повідомлення. Поточні зміни можна експортувати — вони не перезапишуть чужий знімок.

## Повідомлення про технічні роботи

Під час запланованого оновлення користувач бачить «Ведуться технічні роботи».
У разі помилки застосунку — нейтральне повідомлення та кнопку повторної спроби.
Технічні подробиці й код звернення записуються в журнал на комп’ютері.

Увімкнути або вимкнути режим у папці проєкту:

```powershell
.venv\Scripts\python.exe -m scripts.maintenance on
.venv\Scripts\python.exe -m scripts.maintenance off
```

Після зміни режиму оновіть сторінку. Після оновлення коду перезапустіть сервер.

«Спробувати демопрофіль» завантажує приклад із фільмами та серіалами. Це демонстрація,
а не ваша історія. Очищення поточного профілю також очищає автоматичний знімок;
іменовані локальні копії залишаються.
Збережені профілі спільні для користувачів цієї інсталяції.

## На іншому комп’ютері

Розпакуйте архів, установіть Python 3.10 або 3.11 і відкрийте термінал у папці проєкту.
Для Windows:

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m scripts.download_data
.venv\Scripts\python.exe -m scripts.download_movies
.venv\Scripts\python.exe -m scripts.download_series
.venv\Scripts\python.exe -m scripts.download_metadata
$env:OPENBLAS_NUM_THREADS='1'
.venv\Scripts\python.exe -m scripts.train --expanded
.venv\Scripts\python.exe -m streamlit run app/streamlit_app.py --server.address=127.0.0.1
```

Дані завантажуються окремо; їх, навчену модель і персональні профілі не включено в архів.
Інтернет потрібен для встановлення, оновлення каталогу й показу зображень.
Зображення ввімкнено за замовчуванням; їх можна вимкнути. Підбір і рекомендації
працюють із локальними даними навіть без інтернету.

## Що є в каталозі

10 123 фільми з MovieLens 100K + latest-small і 602 серіали зі знімка TVmaze.
Додані «Темний лицар», «1+1», «Інтерстеллар». «Леон» був під назвою The Professional;
тепер він має українську назву й знаходиться також за Léon або Leon.
Це частковий локальний каталог фільмів до 2018 року, а не всі сучасні релізи.
У режимі «Усе» зазвичай показуються п’ять фільмів і п’ять серіалів.

Серіали рекомендуються за змістом описів, жанрами й оцінками TVmaze. Спільних індивідуальних
оцінок серіалів для навчання collaborative-моделі немає. Пояснення в інтерфейсі
це враховують. Українські назви отримано з Wikidata зі зіставленням за IMDb-ID.
Перевірений знімок має 6 048 українських назв фільмів і 387 назв серіалів.
71 назву лише латиницею вилучено з фільтра українських назв.
Український режим за замовчуванням показує лише історії з такими назвами.
Вимкніть «Лише з українськими назвами», щоб побачити також оригінальні назви
для історій без підтвердженого перекладу. Пошук розуміє обидві мови.

Посилання на зображення є для 9 395 фільмів і 602 серіалів. Для інших є позначка відсутності.
Джерело української назви й зображення доступне в картці; права на постери
належать відповідним правовласникам, а не автору цього застосунку.

«Не дивився» не знижує оцінку та не приховує історію з рекомендацій.
Список таких історій зберігається разом із профілем; його можна повернути в підбір.

Метрики у «ML Lab» виміряні тільки для фільмів MovieLens.
Повні деталі й умови використання даних наведено в [README](README.md).

## «Не цікавить»

На картці рекомендації натисніть **Не цікавить**. Назва зникне, а схожі жанри
отримають невелике зниження пріоритету. Це окремий сигнал, а не оцінка 1 ★,
і він не забороняє жанр повністю. Останню дію можна скасувати одразу;
усі такі назви є в **Мої оцінки → Історії, що не цікавлять**, де можна
скасувати конкретний вибір або весь список. Автозапам’ятовування зберігає зміни;
якщо його вимкнено, збережіть профіль вручну.

Оновлений підбір навчено на реальних оцінках розширеного каталогу. Його метрики
показують компроміс між кількістю влучних результатів та їхнім порядком;
загального гарантованого приросту точності не заявлено. Деталі у README.

Порівняння зі схожими проєктами та наступні пріоритети: [звіт](docs/github-comparison.md).

## Docker

Docker Desktop перевірено: усі 61 тест пройшли в Linux / Python 3.11.
Інструкція підготовки даних і запуску є в [README](README.md#docker).
Compose використовує постійні томи для даних/профілів і моделей; перезапуск
контейнера не очищає їх. Локальний запуск на цьому ПК залишився доступним за
звичним посиланням. Контейнер не замінює автентифікацію для публічного сервісу.

## Новий змістовий добір та ML Lab

У «Для вас → Рекомендації» опишіть тему короткою фразою українською чи англійською,
наприклад «космос», «дружба» або «space exploration». Це пошук за описами, а не чат.
Модель **За змістом** використовує навчені TF-IDF + LSA. **Адаптивна** поєднує
оцінки, описи та якість спільноти з вагами з окремого експерименту.
Картка «Докладніше» містить опис і посилання на його джерело.

Перед «Не цікавить» оберіть, що саме мається на увазі:

- **Саме ця історія** — виключити лише її.
- **Схожі теми** — також м’яко знизити пріоритет спорідненого змісту.
- **Не зараз** — пропустити тільки на поточну сесію.

У **Моя бібліотека** зібрано «Переглянути пізніше» та «Мої оцінки».
У **ML Lab** видно справжні рекомендації до / після останньої відповіді,
порівняння моделей і результати експерименту. Метрики MovieLens 1M стосуються
окремого набору фільмів; вони не вимірюють якість серіалів чи задоволення користувачів.

Після початкового встановлення додайте описи й відтворіть експеримент:

```powershell
.venv\Scripts\python.exe -m scripts.download_content
.venv\Scripts\python.exe -m scripts.download_benchmark
$env:OPENBLAS_NUM_THREADS='1'
.venv\Scripts\python.exe -m scripts.benchmark_v3
```

Після цього перезапустіть сайт. MovieLens 1M потрібен лише для незалежного
експерименту; він не змінює ID ваших фільмів або персональні списки.
