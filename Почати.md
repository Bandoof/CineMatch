# CineMatch v1.3 — як почати

Для кандидата v1.4 є окремий [безпечний деморежим](docs/portfolio-demo.md):
`python -m streamlit run app/portfolio_app.py --server.address=127.0.0.1`.
Він показує реальні метадані й синтетичний профіль, не відкриваючи приватний SQLite.
Повний ML-показ потребує явно підготовленого public pack. v1.4 ще в review PRs;
публічного розгортання немає. Нижче описано звичайний локальний режим.

**Історії, що залишаються з вами.** Локальний застосунок для пошуку фільмів і
серіалів, персональних рекомендацій та власної бібліотеки. Українська — мова
за замовчуванням; перемикач English завжди є у верхній частині сторінки.

## Чисте встановлення

Потрібен Python 3.10 або 3.11. У PowerShell на Windows:

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m scripts.sync_catalog --directory data/discovery --pages 1
.venv\Scripts\python.exe -m streamlit run app/streamlit_app.py --server.address=127.0.0.1
```

Відкрийте [CineMatch](http://127.0.0.1:8501). TVmaze працює без ключа. Збережені
серіали доступні без тренувального набору. У кандидата v1.4 свіже встановлення без
попереднього кешу має невелику датовану добірку з 30 реальних назв; назви не вигадуються.
На Linux/macOS команди ті самі після `source .venv/bin/activate`, з `python`
замість `.venv\Scripts\python.exe`. Якщо середовище вже налаштоване, можна
скористатися збереженим **START_CINEMATCH.cmd**; журнал — `data/runtime/server.log`.

Щоб додати історичні фільми та наявні ML-алгоритми, виконайте:

```powershell
.venv\Scripts\python.exe -m scripts.download_data
.venv\Scripts\python.exe -m scripts.download_movies
.venv\Scripts\python.exe -m scripts.train
```

Це офіційні MovieLens 100K і latest-small development snapshots, не новий holdout.
За відсутності локальної моделі застосунок може навчити її при першому запуску,
що займає більше часу. Історичні результати досліджень не перезаписуються.
Wikidata/Wikipedia-імена й зображення для старого каталогу можна отримати через
`python -m scripts.download_metadata`: окреме відновлюване завантаження багатьох
запитів. Воно необов’язкове для відкриття застосунку.

## Відкривайте, знаходьте, зберігайте

- **Відкривайте:** нещодавні й майбутні релізи за підтвердженими датами,
  історична популярність MovieLens та прозоро визначені колекції.
- **Для вас:** оцініть кілька знайомих історій або одразу переглядайте підбір.
  Старий каталог використовує Adaptive; нові назви — окремо позначений жанровий
  fallback із доступною реальною оцінкою джерела.
- **Фільми / Серіали / Пошук:** українські, англійські й оригінальні назви,
  транслітерація, частини назв, друкарські помилки, жанри, роки й порядок.
- **Детальніше:** лише доступні реальні описи, постери, актори, автори, тривалість,
  оцінки з джерелом і підтверджені офіційні трейлери. Саме відкриття не означає
  перегляд. Відсутній український опис має пояснений мовний fallback.
- **Моя бібліотека:** дивитися пізніше, переглянуто, власні оцінки, не цікавить,
  відкладено на сесію та реальні зміни поточної сесії. Фільтруйте й сортуйте списки.
- **Дослідження:** алгоритми й наявні ML-звіти окремо від звичайного перегляду.

У деталях можна додати до списку, явно позначити перегляд або зберегти оцінку.
Оцінена назва стає переглянутою й прибирається зі списку. Позначка перегляду без
оцінки не додає вигаданих зірок. **Скасувати останню дію** відновлює попередній
стан. Undo й snooze діють у поточній сесії. Щоб повернути оцінену назву до
непереглянутих, спочатку приберіть свою оцінку; обидві дії явні та з Undo.

## Пам’ять і резервні копії

Автозапам’ятовування ввімкнене: бібліотека й мова відновлюються після reload.
Це один спільний поточний профіль цієї інсталяції, без облікових записів.
SQLite залишається на вашому ПК; клонування Git його не переносить.
У бібліотеці відкрийте **Профілі та резервна копія**: іменовані копії та JSON
імпорт/експорт. Старі формати 2–5 і початкові словники оцінок сумісні.

Нові provider IDs за потреби додають формат 6 із мінімальними посиланнями на
назви. Вони відновлюються без кешу, але без вигаданих повних метаданих.
Старі версії CineMatch не читають формат 6: зберігайте вихідні резервні копії.
Пошкоджений імпорт не змінює бібліотеку. Конфлікт іншої вкладки або помилка
SQLite не перезаписує збережений знімок; поточні дані можна експортувати.

`CINEMATCH_PROFILE_DB` обирає окрему БД; `CINEMATCH_AUTOSAVE=0` вимикає
автопам’ять; `CINEMATCH_LOCAL_PROFILES=0` вимикає локальні профілі.
Для classic-інтерфейсу: `CINEMATCH_UI=classic` і окрема БД, якщо основний профіль
містить сучасні назви. [Сумісність і rollback](docs/product-ui.md).

## Нові релізи й офлайн

Збережений каталог працює без API. Постери — зовнішні посилання: без інтернету
вимкніть **Показувати постери**. Оновлення каталогу й пошук у джерелах явні;
оцінки та списки не надсилаються провайдерам. Застарілі дані мають дату отримання.

Для сучасних фільмів TMDB необов’язковий токен налаштовується лише в середовищі
процесу: `TMDB_READ_ACCESS_TOKEN`. Не додавайте справжній токен у Git або JSON.
Без нього TVmaze й офлайн-каталог залишаються доступними. TVmaze — CC BY-SA;
TMDB має власні некомерційні умови, logo/notice та окрему комерційну ліцензію.
[Джерела, ліцензії та конфігурація](docs/catalog-providers.md).

У перевіреному публічному QA-каталозі: 10 123 історичні фільми та 973 серіали;
32 серіали вперше вийшли з 2023 року. Це часткове покриття. Live TMDB не перевірено
через відсутність токена; тести його контрактів не видаються за live-покриття.

## Перевірки та обмеження

[Фактичні screenshots і звіт v1.3](docs/release-v13.md) · [Архітектура](docs/architecture.md).
Історичні +17,8% **не підтверджено**; cohort із 326 користувачів уже використано.
Новий holdout не запускався, старі результати не переписано. Synthetic latency
не означає швидкість на кожному Windows-ПК або покращення якості рекомендацій.
Застосунок не розгортався публічно; локальний SQLite не є захищеним multiuser-сервісом.

Якщо джерело недоступне, користуйтеся кешем. Якщо кеш пошкоджено, вихідний файл
зберігається. Якщо відсутні назви, перевірте каталожну директорію та явно оновіть її.
Технічні роботи можна ввімкнути через `python -m scripts.maintenance on`,
вимкнути через `python -m scripts.maintenance off`; стартові помилки залишаються
за нейтральною сторінкою з локальним кодом звернення.
