# Real portfolio media / Справжні матеріали показу

Captured 2026-10-10 from the running local `app/portfolio_app.py`, source branch
`codex/v14-browser-performance`, Chromium 153 / Playwright 1.63. Desktop 1440×1000,
mobile 390×844, tablet 768×1024. Frames show the labeled synthetic profile and
actual public catalog/model behavior. No owner profile/database, token, fabricated
screen, generated artwork or unimplemented feature is included.

The public demo pack was independently prepared from checksum-verified official
MovieLens development archives: 222 training titles / 29,974 canonical latest
events / 248 combined identities. Source data and models are **not** in Git.
The dated metadata fixture has 22 films / 8 series; provider links are visible.
New shared captures disable posters, avoiding bundled third-party artwork.

Files:

- `desktop-discover.png`, `desktop-collections.png`: actual first launch and collection.
- `desktop-search.png`, `desktop-movie-details.png`, `desktop-series-details.png`: Ukrainian search and source details.
- `desktop-for-you.png`, `desktop-ml-cards.png`: explicit original Collaborative mode.
- `desktop-library.png`, `desktop-research.png`: example preferences and scientific limits.
- `mobile-discover.png`, `mobile-details.png`, `tablet-discover.png`, `tablet-details.png`: actual responsive views.
- Local-only `qa-walkthrough.mp4` (outside Git, not uploaded): short silent browser QA footage, **not** a finished narrated 3–5-minute portfolio video. Its metadata/hash is recorded in `provenance.json`; the owner must approve publication separately.
- `demo-uk.srt`, `demo-en.srt`: draft four-minute captions for the storyboard; real final recording alignment is still required.
- `provenance.json`: capture source, file hashes, browser and video information.

Repository screenshots are genuine captures of implemented UI; they were not
edited into synthetic screens. The video is transcoded from actual browser
capture; no fictitious clicks or scenes are composited. Metadata visible in TVmaze
