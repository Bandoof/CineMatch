# Public demonstration metadata — separate from the MIT code license

Wikidata structured labels, descriptions and statements are dedicated to the
public domain under [CC0](https://www.wikidata.org/wiki/Wikidata:Licensing).
Movie entries and Ukrainian labels come from the linked QIDs in `sources.json`.
No translation, synopsis, cast, rating or popularity value was generated.

TVmaze metadata is used under [CC BY-SA 4.0](https://www.tvmaze.com/api#licensing).
TVmaze series records and adaptations are redistributed under
[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Each record links
to its original show ID; adaptations add independently sourced CC0 Ukrainian
labels only after unique IMDb/type/year matching. Other fields retain TVmaze
provenance and retrieval dates. Attribution is shown in the application.

Artwork is **not bundled**. Eight TVmaze CDN URLs are hotlinked as permitted by
the API documentation; artwork remains subject to its rights holders' rights.
No blanket image license or complete legal compliance certification is claimed.
Wikidata movies have neutral missing-artwork fallbacks and no community ratings.

This is a 30-title dated selection, not a complete catalog or a live release feed.
Conflicting release statements separated by more than 180 days are omitted;
day-precision source dates do not guarantee local theatrical/streaming availability.
Short Wikidata descriptions are labeled as such, not presented as film synopses.
Optional TMDB integration remains separately licensed/configured; this sample
contains no TMDB metadata, API key, private profile or individual training ratings.
